# Plan 6.2: QC Approval Interface

## Objective
Add a QC (Quality Control) approval workflow to the mechanic dashboard. When a job is completed, the lead mechanic can upload proof images (photos of finished work) and submit for QC sign-off. A lead mechanic or manager can then approve the QC.

## Context
- The `jobs` table already has `qc_images` and `qc_approved_by` fields (added in Phase 3).
- Image upload uses the shared `uploadAttachment` function from `@shared/nocodb-adapter.js` (exposed via `window.pb` wrapper or direct import).
- The mechanic page from Plan 6.1 already shows active jobs.
