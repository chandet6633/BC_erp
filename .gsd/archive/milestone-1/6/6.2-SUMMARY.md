# Summary 6.2: QC Approval Interface

## Implementation
- QC panel is a collapsible section on each job card, toggled by a "📷 QC" button
- File input uses `accept="image/*" capture="environment"` for camera-first on mobile
- Uploads go through `uploadFiles()` from `@shared/attachmentService.js` (compresses images before upload via `/api/upload` proxy)
- Existing and new images are merged into a JSON array stored in `qc_images`
- `renderAttachments()` renders clickable thumbnails; clicking opens fullscreen image viewer modal
- Approval button visible to `manager`, `owner`, `admin`, `sa` roles; sets `qc_approved_by` with user's name
- QC status badge shown on each card: "📷 รอตรวจ QC" or "✅ QC อนุมัติ"
