# Summary 6.3: Mechanic KPI View & Build Verification

## KPI Role-Gating
- **All roles:** Jobs Led count, Jobs Assisted count (always visible)
- **Manager / Owner / Admin only:** Hours Worked, Total Jobs Completed, Revenue Generated
  - Controlled by `canSeeFinancials = ['manager', 'owner', 'admin'].includes(role)`
  - `.manager-only` CSS class set to `display:none` by default; shown conditionally in `init()`

## Data Source
- Fetches closed jobs with `filter: "(status='closed')"` and filters client-side to the current month using `start_date`/`end_date`
