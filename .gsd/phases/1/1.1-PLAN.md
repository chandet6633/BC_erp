# Plan 1.1: Initialize Playwright Test Infrastructure

## Objective
Set up the Playwright testing environment in a dedicated `tests/e2e/` folder to begin end-to-end testing for both MungkhudShop and the Portal. We need to avoid interactive CLIs that might hang the automation, so we'll construct the config manually.

## Context
- `webapp/tests/e2e/` will contain the Playwright tests.
- We need a `package.json` scoped to the testing directory to install `@playwright/test`.
- The testing strategy calls for Page Object Models and reusable authentication fixtures.

  <files>

    tests/e2e/playwright.config.js
    tests/e2e/utils/auth.js
  </files>
  <action>
    - Create `tests/e2e/` directory if it doesn't exist.
    - Write `tests/e2e/package.json` with `@playwright/test` as a dev dependency.
    - Write `tests/e2e/playwright.config.js` pointing to standard local ports (e.g., MungkhudShop at 8080 or the dev server port, Portal at 8081).
    - Write an initial authentication utility `utils/auth.js` that can log into the portal and save state (to avoid logging in before every single test).
