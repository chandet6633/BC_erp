# Plan 4.1: Print Engine & Settings

## Objective
Update the `settings.js` module to accept Logo and QR Image uploads, and create a `print-engine.js` utility that compiles job data into a printable invoice layout.

## Context
- .gsd/ROADMAP.md
- MungkhudShop/src/pages/settings.js
- shared/nocodb-adapter.js
- MungkhudShop/src/pages/job.js

## Tasks

<task type="auto">

    - Add a textarea for `qr_payment_text` (Payment Instructions).

  </files>
  <action>
    - Create `print.css` to hide standard UI elements (`.sidebar`, `.header`) and format a clean A4 layout (`@media print`).
