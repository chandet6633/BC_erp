# Plan 3.1: Admin & Manager Role Testing

## Objective
Write E2E tests for the Management Portal to verify that Admin and Manager roles have full access to sensitive data (financial KPIs, HR modules) and cannot be blocked by unexpected UI dead-ends.

## Context
- `webapp/tests/e2e/specs/management-admin.spec.js`
- `webapp/tests/e2e/specs/management-manager.spec.js`

## Tasks
