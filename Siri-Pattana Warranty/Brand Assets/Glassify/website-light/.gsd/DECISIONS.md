# Architecture Decision Log

## 1. Vanilla HTML/JS Architecture
- **Date**: 2026-05-07
- **Context**: Deciding on whether to refactor the site into a framework (e.g., React/Next.js) or keep it as is.
- **Decision**: Keep Vanilla HTML, CSS, and JS.
- **Rationale**: The site is extremely fast and lightweight. Refactoring adds unnecessary complexity for a simple marketing site. Node scripts will suffice for any templating/batch updates.
