## Content Production Tips

### ถ่ายทุกครั้งที่ติดตั้ง

- [ ] 📸 ไฟหน้าเดิม (ก่อน) — กลางวัน + กลางคืน
- [ ] 📸 ระหว่างติดตั้ง — ช่างกำลังทำงาน
- [ ] 📸 ไฟเปิดใช้งาน (หลัง) — มุมเดียวกับ "ก่อน"
- [ ] 📹 วิดีโอ 10 วินาที — ลำแสงบนถนน (กลางคืน)
- [ ] 📸 ลูกค้าถ่ายรูปกับรถ (ขออนุญาตก่อน)
- [ ] 📝 ถามลูกค้า "ใช้ซีรีส์ไหน? ชอบอะไรมากสุด?"

### Batch Production วันเสาร์

1. เลือกรูป/วิดีโอที่ดีที่สุดจากสัปดาห์นี้ (3-5 ชิ้น)
2. เขียน caption + ใส่ hashtag
3. ตั้งเวลาโพสต์ล่วงหน้า (Meta Business Suite / Later)
4. เตรียม LINE broadcast

## Visual Template Checklist (Canva/Photoshop)

- [ ] **Before/After Split** — 2 ช่องเทียบ (กลางวัน+กลางคืน) + โลโก้ + ราคา
- [ ] **Product Series Card** — 4 ซีรีส์ สี accent
- [ ] **Night Test Shot** — ลำแสงบนถนน มืดๆ dramatic
- [ ] **Customer Review** — รูปลูกค้า + คำพูด + ⭐⭐⭐⭐⭐
- [ ] **Infographic** — พื้นมืด + ข้อมูล + 💡 icon
- [ ] **Promo Banner** — ราคา + ส่วนลด + deadline
- [ ] **YouTube Thumbnail** — Before/After + bold text + 💡
- [ ] **TikTok Cover** — แนวตั้ง + 1 บรรทัดหัวข้อ
