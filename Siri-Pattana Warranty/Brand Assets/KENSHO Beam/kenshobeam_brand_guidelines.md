## 1. Brand Identity

### What is KENSHO Beam?

**KENSHO Beam** (เคนโช บีม) คือแบรนด์ไฟหน้า LED ประสิทธิภาพสูงของ BC AutoXperience — ชื่อมาจากภาษาญี่ปุ่น 顕照 (kensho = แสงที่ปรากฏ / แสงแห่งการเปิดเผย) + Beam (ลำแสง) สื่อถึงเทคโนโลยีคุณภาพสูง ความสว่างที่ปรากฏชัดเจนเหนือทุกมาตรฐาน ครบ 4 ซีรีส์ ครอบคลุมทุกกลุ่มลูกค้า พร้อมบริการติดตั้งฟรีและรับประกันถึง 3 ปี

### Brand Promise

> "สว่างที่สุดเท่าที่เคยมี เปลี่ยนไฟหน้าธรรมดาให้เป็นแสงแห่งการเปิดเผย"

### Brand Personality

| Trait | Description |
|---|---|
| **Powerful** | Light Revealed. — สว่างชัดเจน เหนือกว่าทุกคู่แข่ง |
| **Japanese-tech** | 顕照 — เทคโนโลยี LED ระดับพรีเมียม ชิป CSP / Flip Chip |
| **Reliable** | CANBUS Ready ทุกรุ่น — ไม่ error ไม่กระพริบ |
| **Accessible** | เริ่มต้น ฿2,490/คู่ · ติดตั้งฟรี · ประกันสูงสุด 3 ปี |
| **Innovative** | LumiSync™ Bluetooth เปลี่ยนสีไฟได้ — รุ่นแรกในเซกเมนต์ |

### Tagline

> **Light Revealed.**

ใช้ใน: bios, banners, video intros, packaging, website hero
เขียนเป็นภาษาอังกฤษ ตัวพิมพ์ใหญ่ต้นคำ จุดที่ท้าย

### Secondary Tagline (Thai)

> **สว่างที่สุดเท่าที่เคยมี**

## 2. Logo

### Primary Logo — Wordmark

| Element | Style | Effect |
|---|---|---|
| **顕照 Kanji** | Shippori Mincho 800 | Stacked vertically, white on dark, traditional authority |
| **"KENSHO"** | Orbitron Bold 700 | Modern tech typography, white with blue accent slash |
| **"B E A M"** | Orbitron Regular 400, spaced | Electric blue (#0EA5E9), subtitle beneath KENSHO |
| **Blue Slash** | Angled line | Separates kanji from English text, electric blue (#0EA5E9) |

### Logo Usage Rules

- **Clear space:** Minimum 1× the height of the kanji block on all sides
- **Minimum size:** 24px height (digital), 10mm (print)
- **Preferred background:** Dark (#050508) or very dark blue-black
- **On light backgrounds:** Use a dark container behind the logo
- **Don'ts:** No rotating, stretching, shadows, changing colors, or separating "KENSHO" from "Beam"

### Logo Variations

| Variation | Use Case |
|---|---|
| **Full Wordmark** (dark bg) | Website, banners, signage |
| **"KB" Monogram + 顕照** | Profile pictures, app icons |
| **Wordmark + Tagline** | Marketing materials, packaging |

## 8. Photography & Visual Style

### Photo Guidelines

| Type | Style |
|---|---|
| **Before/After** | Split screen, same car — เลื่อนเพื่อเปรียบเทียบ "ไฟเดิม vs KENSHO Beam" |
| **Night Shot** | ลำแสงตัดผ่านความมืด — dramatic lighting on road |
| **Product Shot** | Dark bg, LED bulb with electric blue glow, clean product photography |
| **Installation** | ช่างกำลังติดตั้ง, clean workspace |
| **On-car** | ไฟติดในรถลูกค้า — ถ่ายทั้งกลางวัน + กลางคืน |

### Visual Language

- 💡 **Illumination rays** / light reveal effects as design elements
- **Dark backgrounds** (#050508) with electric blue (#0EA5E9) glow accents
- **Sharp geometric lines** — representing beam precision
- **Japanese 顕照 characters** as subtle watermark/detail element

### Video Elements

- **Intro:** KENSHO Beam logo animation (light reveal → logo appear) → "Light Revealed."
- **Outro:** Logo + "🔧 ฟรีติดตั้ง · 🛡️ ประกันสูงสุด 3 ปี · ✅ CANBUS Ready"
