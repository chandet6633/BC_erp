4. Full Business Flow

  1. Login as SA.
  2. Create or select customer.
  3. Create or select vehicle.
  4. Create a new job with mileage, notes, repair details, and no end date.
  5. Add stock parts and service labor items.
  6. Save job and confirm it appears on Kanban.
  7. Login as Mechanic and update the job status through allowed workflow.
  8. Login as Admin or Manager and complete QC.
  9. Create invoice from the job.
  10. Record payment and receipt.
  11. Verify dashboard totals, customer history, stock ledger, and finance report.
Pass only if each role can complete their part without using admin credentials as a workaround.
